# Provenance & Content Hygiene

This component provides one conservative policy and one deterministic audit engine for drafts and files moving between ChatGPT, Claude, Gemini, editors, repositories, and publication workflows.

## Why it exists

A user may supply substantial original work to a model for editing, formatting, critique, translation, or restructuring. That assistance should not silently become a claim that the underlying work was generated by the model. Likewise, hidden Unicode or software metadata should not be allowed to blur the distinction between authorship, assistance, and file provenance.

The toolkit therefore separates:

- authorship of the underlying draft or ideas;
- model assistance applied to that material;
- file-level provenance or metadata added by software.

It does not attempt to make prose "look human" to detectors.

## Install for Claude Code and Gemini CLI

From the `research-kit` checkout:

```bash
python3 scripts/install_provenance_hygiene.py --all
```

This installs:

- shared deterministic engine at `~/.phirilab/provenance-hygiene/provenance_hygiene.py`;
- Claude skill at `~/.claude/skills/provenance-content-hygiene/`;
- Gemini extension at `~/.gemini/extensions/phirilab-provenance-hygiene/`.

Restart active Claude Code and Gemini CLI sessions after installation so persistent instructions reload.

Install only one adapter with `--claude` or `--gemini`. Use `--dry-run` to inspect intended writes.

## Standalone use with any model output

Inspect without changing a file:

```bash
python3 ~/.phirilab/provenance-hygiene/provenance_hygiene.py inspect draft.md --json
```

Conservatively clean a UTF-8 text file:

```bash
python3 ~/.phirilab/provenance-hygiene/provenance_hygiene.py clean draft.md \
  --output draft.cleaned.md \
  --audit draft.cleaned.audit.json
```

The default text cleaner removes U+200B ZERO WIDTH SPACE and interior U+FEFF only. It preserves multilingual shaping and directional characters for review rather than deleting them automatically.

## Gemini commands

The extension adds `/provenance:inspect` and `/provenance:clean` prompts. Gemini's current extension architecture loads persistent context from `GEMINI.md` and custom commands from extension command files. The commands ask Gemini to use the locally installed deterministic engine rather than inventing its own watermark test.

## ChatGPT

`integrations/chatgpt/provenance-instructions.md` contains the same persistent policy in a form suitable for a project, custom GPT, or other instruction surface. The deterministic engine remains model-independent and can be run on copied or exported text from any platform.

## What the tool does not establish

A clean scan does not prove human authorship. A finding does not prove AI authorship. Invisible Unicode may be legitimate, particularly in multilingual text. Metadata may be legitimate provenance. Host applications may add metadata after model-visible text has been generated.

The safe claim is narrower: the tool reports what it can observe, removes only the conservative character set when asked, and records the before/after file hashes.

## Upstream influence

The inspection-first, fail-closed, and multilingual-safety principles were informed by review of `guillaumemeyer/watermarks-remover`, but this implementation is original and deliberately excludes statistical detector-evasion rewriting and automatic C2PA destruction.
