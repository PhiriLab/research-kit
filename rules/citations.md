# Citations

Always loaded. Reference errors in this domain are caught downstream, manually, under deadline. This rule moves the catch to the point of generation. The style is not fixed here. The discipline is.

## Style follows the user or the output

- The citation style is whatever the user states as their preference, or whatever the target output demands. A journal, a funder template, or a thesis handbook sets the style. The user's stated preference sets it otherwise.
- Ask or check for the required style before formatting a reference list. Do not default to a house style that the target does not want.
- One document, one style. Do not mix styles within a single document.
- If a conversion between styles is needed, do it as a final, explicit, human-checked step, and keep the working corpus in one consistent style until then.

## The DOI constraint

This is the rule that pays for the file, and it holds regardless of style.

- A generated reference never appears without a resolvable DOI. No DOI, no reference.
- If a real source genuinely has no DOI, for example an older book or a grey-literature report, that reference is marked `NO-DOI: verified by <who>, <date>` and carries a stable alternative locator such as an ISBN or a permanent URL. It is never left bare.
- A DOI that has not been resolved is treated as absent. Print it, resolve it, then trust it. Confidence 0.0 on any DOI that has not been checked against the resolver.

## Anti-fabrication

- Do not invent an author, a year, a title, a journal, or a DOI. A plausible-looking reference is worse than a missing one because it survives a skim.
- If the source cannot be verified, say so in place: `UNVERIFIED: <what is missing>`. Do not smooth it into the reference list.
- When reconstructing a reference list, resolve every DOI before the list is considered complete. An unresolved entry blocks completion.

## Practical order of operations

1. Draft the claim.
2. Attach the source.
3. Resolve the DOI.
4. Confirm the required style.
5. Only then format.

A reference that reaches formatting without passing step 3 is a defect.
